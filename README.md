# 🌐 Animated-Website-with-GSAP

A responsive and stylish website built using **HTML**, **CSS**, and **JavaScript**. This project showcases a modern layout with interactive elements and animations.

## 🔍 Overview

This website includes:
- Custom sections with styled content boxes
- Responsive layout using Flexbox
- Interactive buttons and hover effects
- Scroll-based animations (GSAP ready)
- Clean, maintainable CSS structure

## Technologies Used

- HTML5
- CSS3
- JavaScript 
- [GSAP](https://greensock.com/gsap/) (for animations)
- Vercel (for deployment)

## Preview

You can view the live version here: [Live Site Link](https://animated-website-with-gsap.vercel.app/)</br>

## 🛠 Setup & Installation

To run the project locally:

1. Clone this repo:
   ```bash
   git clone https://github.com/YuiSurbhi/-Animated-Website-with-GSAP.git
   ```
- Open the folder in VS Code.
- Use Live Server extension to launch it in the browser.
